Operations & Lean

MARZBALANCE

Line balancing · HTML

MARZBALANCE is a self-contained production line-balancing tool — a single HTML file, no install required. Enter the operators, cycle time and efficiency for each station; it computes the effective time and per-operator takt, flags the bottleneck, and shows the resulting line cadence and pieces per hour. A what-if simulation tells you where adding one operator most improves throughput, and it checks the total time against your target. All data stays in your browser. Open it in any browser and balance the line.

MARZOEE

OEE calculator · HTML

MARZOEE is a self-contained OEE calculator — a single HTML file, no install required. Enter planned time, downtime, ideal cycle time, total pieces and rejects, and it computes Availability × Performance × Quality = OEE in real time, with a bar for each component, a world-class / good / to-improve classification and built-in sanity checks. Record each shift to a history to track the trend. All data stays in your browser, with one-click export and import. The single number every operations manager should watch.

ROI & payback · HTML

MARZROI is a self-contained ROI & payback calculator — a single HTML file, no install required.
